## dt(프레임 간격)가 어긋날 수 있는 경우

OneEuro 필터는 매 호출의 타임스탬프 차이(dt)로 주파수를 갱신하고, dt에
따라 스무딩 강도(alpha)가 달라진다. `timestamp`를 안 넘기면 파이프라인
내부 Stopwatch(벽시계 경과)를 쓴다. 케이스별 정리:

| 상황 | 내부 시계로 충분한가 | 이유 |
|---|---|---|
| 라이브 카메라 스트림 | O | 처리 시각 ≈ 프레임 도착 시각. dt가 실제 시간 흐름과 일치 |
| 프레임 스킵(busy drop, 예제의 `_isBusy` 패턴) | O | 건너뛴 시간만큼 dt가 커지고, 필터가 자동으로 원본 추종 쪽으로 적응 — 올바른 동작 |
| 앱 일시정지/백그라운드 복귀 | O | 매우 큰 dt → alpha≈1 → 사실상 리셋처럼 새 위치에 즉시 스냅 |
| **녹화 영상을 루프로 빨리 처리** | **X** | 30fps 영상을 5ms 간격으로 돌리면 필터는 200fps로 인식 → alpha가 작아져 과도한 스무딩 + 랙. 반대로 느리게 돌리면 스무딩이 거의 안 걸림 |
| **영상 배속/슬로모션 재생** | **X** | 화면상 움직임 속도와 필터가 가정하는 시간이 어긋남 |
| 재현 테스트(같은 프레임 반복 입력) | X | 내부 시계 기준이면 매 실행 dt가 달라져 결과가 비결정적 |

→ 오프라인/녹화 처리에서는 반드시 프레임 PTS를 넘길 것:
`pipeline.process(frame, timestamp: Duration(microseconds: idx * 1000000 ~/ fps))`

타임스탬프 규칙: **단조 증가**여야 하며, 같거나 과거인 타임스탬프가 오면
그 프레임은 필터링 없이 통과한다(공식 구현과 동일). 절대값은 의미 없고
간격만 쓰인다.

## 스무딩을 켜면 생기는 상태(stateful) 특성

- 같은 프레임을 두 번 넣어도 결과가 다르다(이전 프레임 히스토리에 의존).
  프레임 단위 골든 테스트는 스무딩을 끄고 돌릴 것.
- 필터 상태 리셋 시점: 얼굴 소실 후 재획득, 입력 종류/크기/회전/미러
  변경, `resetTracking()`, 멀티페이스 트랙 드롭, 랜드마크 개수 변경
  (468↔478 모드 전환). 이 프레임들은 무필터 통과로 새 시퀀스를 시작한다.
- 다음 프레임 ROI는 항상 **원본(비스무딩) 랜드마크**로 유도된다 —
  스무딩은 출력 전용이며 트래킹 동작에 영향이 없다.

## 어떤 앱은 끄는 게 맞다

- 프레임 단위 측정/캘리브레이션(거리 측정, 의료성 측정): 시간적으로 섞인
  좌표는 "지금 이 순간의 위치"가 아니다.
- 랜드마크를 자체 필터(칼만 등)에 넣는 앱: 이중 필터링은 랙만 누적된다.
- 정지 이미지 단건 처리: 효과가 없고 상태만 생긴다(첫 프레임은 어차피
  통과).

## 튜닝 가이드 (`LandmarkSmoothingOptions`)

- 기본값 = 공식 FaceLandmarker 스트림 모드
  (`min_cutoff 0.05 / beta 80 / derivate_cutoff 1.0`): 반응성 우선.
  정지 지터 −21%, 모션 lag ~4px(얼굴 폭의 ~1%) — uvc 영상 실측.
- `beta`↓(예: 10): 지터 감쇠↑(2차 차분 −30%) / 모션 lag↑(~22px).
  정적인 시나리오(정면 응시, 측정 UI)에만 권장.
- `minCutoff`↓: 정지 시 스무딩 강도↑, 느린 움직임까지 눌러 랙 체감↑.
- 속도 정규화(`disableValueScaling`)는 끄지 말 것 — 꺼지면 같은 파라미터가
  얼굴 크기/해상도에 따라 다르게 동작한다.

## default-on 전환 계획

공식 FaceLandmarker는 스트림 모드에서 스무딩이 기본이다. 이 패키지는
무파괴 원칙(minor에서 기존 사용자의 출력 불변) 때문에 2.4.0에서 opt-in으로
출시했고, 실사용 검증 후 다음 major(3.0.0)에서 default-on으로 뒤집는 것을
검토한다(ROADMAP 참고). 뒤집을 때는 breaking으로 명시하고
`landmarkSmoothing: null`이 opt-out임을 마이그레이션 노트에 적을 것.
